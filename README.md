# myportfolio

Personal site for **Laxmi Narasimha Reddy Gumreddy**, built with **React + Vite**.

## Local development

```bash
npm install
npm run dev
```

Open the URL Vite prints (usually `http://localhost:5173`).

## Content

Edit JSON in `src/data/` (about, experience, skills, projects, education, contact).

Static assets: `public/images/profile.jpg`, `public/laxmi_resume.pdf`.

## Deploy

Pushes to `main` build with `VITE_BASE_PATH=/myportfolio/` and publish `dist/` to GitHub Pages.
